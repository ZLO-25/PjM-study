    中英術語表¶

    本手冊用到的專有名詞，依主題分組；每個詞附英文、一句白話說明，以及最主要的說明單元。

     怎麼查

 1. 用網站右上角的搜尋，輸入中文或英文都可以
 2. 或依下方分組瀏覽
 3. 點「單元」欄的連結，看完整說明

    基本概念¶

    中文 英文 白話說明 單元
    專案 Project 有開始、有結束、交付獨特成果的一次性工作 T-01
    專案集 Program 一群互相牽動、一起管理才划算的專案 T-01
    組合 Portfolio 組織選擇要投資哪些專案與專案集的整體 T-01
    產品 Product 活得比專案久、持續演進的成果 T-01
    專案管理 Project Management 運用知識與技巧，讓專案達成目標 T-02
    績效領域 Performance Domains PMBOK 7 中，專案必須照顧好的八個面向 T-02
    裁適 Tailoring 依專案情境調整流程的輕重 T-26
    預測式 Predictive 先規劃好、再照計畫執行的做法 T-26
    敏捷 Agile 用短週期交付、從回饋中調整的做法 T-25
    混合式 Hybrid 同一專案中，不同部分採用不同做法 T-26
    發起人 Sponsor 專案的最終負責人，提供資源與支持 T-05
    專案管理辦公室 PMO (Project Management Office) 提供專案管理標準、工具與監督的單位 T-24
    矩陣式組織 Matrix Organization 成員同時向職能經理與 PM 負責的組織 T-20
    職能經理 Functional Manager 部門主管，管人與專業 T-20

    啟動與範疇¶

    中文 英文 白話說明 單元
    商業論證 Business Case 說明為什麼值得投資的文件 T-04
    效益 Benefits 專案成果為組織帶來的價值 T-04
    專案章程 Project Charter 正式授權專案並對齊目標的文件 T-05
    利害關係人 Stakeholder 會影響專案或被專案影響的人 T-06
    權力 / 利益方格 Power / Interest Grid 依權力與利益把利害關係人分成四類 T-06
    需求 Requirement 交付物必須滿足的條件 T-08
    非功能性需求 Non-functional Requirement 效能、可用性、安全等品質要求 T-08
    需求追溯矩陣 RTM (Requirements Traceability Matrix) 把需求連到設計、測試、驗收的表 W-03
    範疇 Scope 專案要做的所有工作與交付物 T-09
    工作分解結構 WBS (Work Breakdown Structure) 把專案拆成可管理的工作包 T-09
    工作包 Work Package WBS 最底層、可估算可指派的工作 T-09
    範疇基準 Scope Baseline 核准的範疇說明、WBS 與 WBS 字典 T-09
    範疇蔓延 Scope Creep 未經核准、一點一點擴大的範疇 T-10
    鍍金 Gold Plating 團隊主動做超出需求的東西 T-10
    漸進細化 Progressive Elaboration 隨資訊增加逐步把計畫做細 T-09

    時程與成本¶

    中文 英文 白話說明 單元
    要徑 Critical Path 決定專案最快完成時間的最長路徑 T-11
    浮時 Float / Slack 工作可延後而不影響完成日的時間 T-11
    趕工 Crashing 加資源壓縮要徑上的工期 T-11
    快速跟進 Fast Tracking 把先後工作改成部分平行 T-11
    三點估算 Three-point Estimation 用樂觀、最可能、悲觀三個值估算 W-06
    不確定性錐 Cone of Uncertainty 越早期，估算誤差越大 T-12
    參考類別預測 Reference Class Forecasting 用類似專案的實際結果做估算基準 P-07
    成本基準 Cost Baseline 核准後、依時間分配的預算 T-13
    實獲值管理 EVM (Earned Value Management) 同時比較進度與成本的方法 T-13
    計畫值 / 實獲值 / 實際成本 PV / EV / AC 應完成的、實際完成的、實際花的 T-13
    時程 / 成本績效指標 SPI / CPI 小於 1 代表落後 / 超支 T-13
    完工估算 EAC (Estimate at Completion) 預估專案最後總共會花多少 W-07
    資源平衡 Resource Leveling 為解決超載而調整時程 T-14
    單點故障 Single Point of Failure 只有一個人或一個元件能做的關鍵環節 T-14

    風險、品質與驗收¶

    中文 英文 白話說明 單元
    風險 Risk 可能發生、會影響目標的不確定事件 T-15
    議題 Issue 已經發生、正在影響專案的問題 T-16
    假設 Assumption 目前當作真的、但尚未證實的前提 T-16
    相依 Dependency 需要別人先完成的工作 W-09
    RAID 日誌 RAID Log 風險、假設、議題、相依的共同追蹤表 W-09
    規避 / 轉移 / 減輕 / 接受 Avoid / Transfer / Mitigate / Accept 四種回應威脅的策略 T-15
    觸發條件 Trigger 啟動風險回應的明確條件 T-15
    事前驗屍 Pre-mortem 假設專案已失敗，找出最可能的原因 P-14
    品質成本 Cost of Quality 預防、鑑定與失敗成本的總和 T-17
    品質保證 / 品質控制 QA / QC 檢查流程 / 檢查產出 T-17
    驗收標準 Acceptance Criteria 交付物被接受的具體可測條件 T-18
    完成定義 DoD (Definition of Done) 團隊對「做完」的共同標準 T-18
    使用者驗收測試 UAT (User Acceptance Testing) 使用者實際操作確認符合需求 W-10
    割接 Cutover 從舊環境切換到新環境 W-11
    回退 Rollback 割接失敗時回到原狀 W-11

    團隊、溝通與治理¶

    中文 英文 白話說明 單元
    RACI 矩陣 RACI Matrix 執行、當責、諮詢、告知的責任分派表 T-19
    當責 Accountable 對結果最終負責的人，每項只能一位 T-19
    啟動會議 Kickoff Meeting 讓所有人對齊目標、範圍與角色的第一次會議 W-13
    溝通管道 Communication Channels n 人之間有 n(n−1)/2 條管道 T-21
    紅黃綠燈 RAG (Red / Amber / Green) 用顏色表示專案健康度 T-22
    西瓜報表 Watermelon Reporting 外面綠、裡面紅的報告 T-22
    升級上報 Escalation 正式請求更高層級協助或決策 W-15
    變更請求 Change Request 修改已核准基準的正式提議 W-16
    變更控制委員會 CCB (Change Control Board) 有權核准重大變更的人或群體 T-23
    治理 Governance 誰有權決定什麼、依據什麼決定 T-24
    階段關卡 Stage Gate 關鍵轉折點的「繼續、調整或停止」決策 T-24
    指導委員會 Steering Committee 決定方向與重大取捨的高階主管群 T-24

    敏捷與流動¶

    中文 英文 白話說明 單元
    衝刺 Sprint Scrum 中固定長度的工作週期 T-25
    產品負責人 Product Owner 決定做什麼、先做什麼的人 T-25
    產品待辦清單 Product Backlog 依優先順序排列的工作清單 T-25
    增量 Increment 每個 Sprint 交付的可用成果 T-25
    回顧會議 Retrospective 團隊檢討做法、決定改善的會議 W-18
    看板 Kanban 視覺化工作並限制在製品的方法 T-27
    在製品上限 WIP Limit 同時進行中的工作數量上限 T-27
    燃起圖 / 燃盡圖 Burnup / Burndown Chart 顯示完成量或剩餘量的趨勢圖 W-17
    結案 Project Closure 正式確認完成、移交與學習 T-28
    經驗回顧 Lessons Learned 記錄可供其他專案參考的經驗 T-29

    心理學名詞¶

    中文 英文 白話說明 單元
    立場 / 利益 Position / Interest 說出口的要求 / 背後真正在乎的 P-01
    變革抗拒 Resistance to Change 對改變帶來的損失的反應 P-02
    影響力交換 Influence through Exchange 用對方重視的東西換取配合 P-03
    原則式談判 Principled Negotiation 聚焦利益、創造選項、用客觀標準 P-04
    最佳替代方案 BATNA 談不成時你能走的最好的路 P-04
    向上管理 Managing Up 讓主管用最少時間做最好的決定 P-05
    規劃謬誤 Planning Fallacy 系統性地低估自己工作的時間與成本 P-07
    沉沒成本 Sunk Cost 已經花掉、拿不回來的投入 P-08
    承諾升級 Escalation of Commitment 因已投入而持續加碼 P-08
    倦怠 Burnout 長期壓力造成的耗竭、疏離與無效能感 P-09
    錨定效應 Anchoring 判斷被第一個數字拉著走 P-10
    心理安全感 Psychological Safety 相信說出問題不會被懲罰 P-11
    團隊發展階段 Tuckman Stages 形成、風暴、規範、表現、解散 P-12
    衝突處理模式 Conflict Modes (TKI) 競爭、合作、妥協、遷就、迴避 P-13
    團體迷思 Groupthink 為了和諧而壓抑異見 P-14
    緘默效應 Mum Effect 不願意傳遞壞消息 P-15
    不究責 Blameless 對事不對人的檢討方式 T-29
