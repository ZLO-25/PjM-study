    C-03 FBI Virtual Case File¶

    一句話摘要：美國聯邦調查局 (FBI) 的電子案件管理系統，在需求不斷變動、管理層頻繁更替的情況下開發多年，最終交付的系統無法使用，專案於 2005 年終止。

    閱讀說明

    本頁區分「已知事實」與「推論詮釋」。事實部分以美國司法部監察長辦公室 (DOJ OIG) 的稽核報告與 IEEE Spectrum 的調查報導為主。

     時間線（概略）

 2000–01  Trilogy 現代化計畫啟動
   │      VCF 是其中的案件管理軟體
   │
 2001     911 事件後，計畫被要求加速
   │      需求大幅改變
   │
 2003     承包商交付第一版，FBI 認為不符需求
   │
 2004     評估是否補救或重新開始
   │
 2005     專案終止
   │      後續由新的案件管理專案接手

    背景¶

    • VCF 是 FBI「Trilogy」資訊現代化計畫的一部分，目標是取代以紙本與舊系統為主的案件管理方式。
    • 2001 年 911 事件後，計畫被要求加速，系統的需求與目標也隨之改變。
    • DOJ OIG 在 2005 年的稽核報告指出，計畫缺乏完整的需求定義、成本與時程管控，以及足夠的資訊科技管理能力。
    • IEEE Spectrum 的調查報導描述了需求文件不斷膨脹、專案期間關鍵管理職位多次更替等情況。
    • 承包商交付的系統被 FBI 認定無法滿足需求；專案在 2005 年初終止，公開報導中常引用的 VCF 投入金額約為 1.7 億美元。
    • 在需求高度不確定、組織急於展現改革成果的情況下，採用一次交付的大型開發方式，風險極高。
    • 管理層頻繁更替使得「誰有權凍結需求、誰有權喊停」更不明確。

    關鍵決策點¶

    1. 在 911 後被要求加速，同時需求大幅改變。
    2. 以一次性交付的方式開發完整系統，而非分階段交付可用的部分。
    3. 需求持續變更，缺乏有效的變更控制。
    4. 第一版交付失敗後，在補救與重新開始之間的抉擇。

    出了什麼事¶

    • 已知：交付的系統不符合 FBI 的需求，且據報導有大量待修正的問題。
    • 已知：專案被終止，部分成果被保留或參考，後續專案重新開始。
    • 推論：問題在後期才全面暴露，代表專案期間缺乏能及早呈現「實際狀態」的機制，例如可運作的中間交付或獨立的品質審查。

    對應理論 (T)¶

    • T-08 需求蒐集與定義：需求長期無法穩定。
    • T-10 範疇蔓延：需求文件持續膨脹。
    • T-24 治理與階段關卡：何時、由誰決定停止。
    • T-05 專案章程與啟動：目標在專案中途被改寫。

    對應心理 (P)¶

    • P-08 沉沒成本與承諾升級：多年投入後要不要停止。
    • P-15 壞消息上報延遲：問題累積到後期才全面暴露（推論）。
    • P-14 團體迷思：急於交付的壓力下，異議是否被聽見（推論）。

    反事實推演¶

    • 分階段交付：先交付最小可用的案件管理功能給部分單位試用，從回饋中修正需求。
    • 需求凍結與變更控制：設定明確的需求凍結點，之後的變更進入下一階段。
    • 事先定義停止條件：例如「若某階段結束時核心功能驗收未過，即進入是否繼續的審查」。
    • 獨立驗證：在開發中期就由第三方進行品質與進度的獨立審查。

    可帶走的教訓¶

    1. 需求不確定時，不要一次交付全部；小步交付能讓問題提早浮現。
    2. 緊急壓力會讓人跳過基本功，但基本功（需求、變更控制）在壓力下更重要。
    3. 管理層穩定性本身就是專案風險，應列入風險管理。
    4. 終止專案不是唯一的失敗；繼續投入一個無法成功的專案，代價更大。

    小測驗¶

    如果在 2002 年你能改變一件事，以下哪一項最可能降低這個專案的失敗風險？

    • A. 增加更多開發人員
    • B. 改為分階段交付，先讓部分單位使用核心功能，並建立正式的需求變更控制
    • C. 延長每日工時
    • D. 只換一家承包商
    看答案與解析

    答案是 B。

    • A 錯： 需求不穩定時加人，只會更快地做出錯誤的東西。
    • B 對： 分階段交付讓需求透過實際使用被驗證，變更控制讓範疇有邊界，見 T-26 混合式與裁適、T-23 整合變更控制。
    • C 錯： 與 A 相同，不改變問題的結構。
    • D 錯： 如果需求與管理的問題沒解決，換承包商也會遇到同樣的困難。
