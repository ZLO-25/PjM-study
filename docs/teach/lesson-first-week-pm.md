# 教案：新任 PM 上工前速讀

**對象：** 下週就要上任的新 PM、第一次帶專案的技術組長　**搭配單元：** [T-03](../theory/T-03-pm-role-and-power.md)、[P-16](../psychology/P-16-rookie-pm-traps.md)、[W-20](../practice/W-20-first-30-days.md)、[T-10](../theory/T-10-scope-creep.md)、[P-15](../psychology/P-15-mum-effect.md)、[T-22](../theory/T-22-status-reporting.md)、[W-21](../practice/W-21-meeting-notes-action-items.md)

這份教案對應首頁的「上工前速讀」路線。它不教框架，只教「新手前三個月最貴的五個錯」以及每個錯的替代行為。

```text
 本堂課的主線：五個最貴的錯 → 五句替代的話

 錯 1  以為 PM 有權力      → 「我能給對方什麼？」
 錯 2  不敢說不知道        → 「我下午前確認後回你。」
 錯 3  什麼都答應          → 「我先記下來，評估後明天回。」
 錯 4  壞消息等有解法再說  → 「有件事可能影響上線日……」
 錯 5  會議開完沒人動      → 「誰、做什麼、哪一天？」
```

## 講義重點

1. **PM 的權力大多不是職位給的**：是資訊、關係與可信度換來的。上任第一件事不是發號施令，而是弄清楚誰在乎什麼。
2. **冒牌者感是正常配備**：幾乎每個新 PM 都有，它不會因為你變厲害而消失；目標是不讓它決定你的行為。
3. **前 30 天先理解、再改變**：10 天聽與讀、10 天對帳、10 天建立節奏。接手初期是重設燈號成本最低的時候。
4. **「順便加一個」的標準回應**：記下來、評估影響、交給有權的人決定。不當場答應，也不當場拒絕。
5. **壞消息的時機**：影響到別人的決策時就要說，即使還沒有解法。「問題加上正在處理」本身就是有價值的資訊。
6. **燈號的意思**：黃燈是「有對策」，紅燈是「我需要幫忙」。紅燈不是失敗，拖到無法挽回才是。
7. **一場會議要留下三樣東西**：決定、行動項目（一人一事一日期）、待定事項。24 小時內寄出。

## 討論題

**1. 你第一次當 PM（或第一次帶人）時，最早犯的一個錯是什麼？當時為什麼會那樣做？**

??? note "引導方向"
    讓有經驗的學員先說，降低新手的防衛心。把答案歸類到五個錯裡，通常都落得進去。追問「當時你心裡在怕什麼？」引導到 [P-16](../psychology/P-16-rookie-pm-traps.md) 的核心：錯誤行為背後多半是不安全感，而不是能力不足。

**2. 主管在走廊上說：「你們既然在改防火牆，順便把新系統的規則加一下，很快吧？」你的第一句話是什麼？**

??? note "引導方向"
    請學員實際說出口，不要只描述。常見錯誤：「好啊」或「這要走變更流程」。前者是討好，後者會被聽成官僚。引導到「好，我先記下來，看一下影響，明天回您」。再追問：明天回的時候要帶什麼？答案是影響（時間、風險）與選項，見 [T-10](../theory/T-10-scope-creep.md)、[W-16](../practice/W-16-change-request.md)。

**3. 你剛接手一個專案，前任的報告都是綠燈，但工程師私下說「不可能準時」。你的第一份週報要怎麼寫？**

??? note "引導方向"
    先讓學員兩兩討論「維持綠燈一個月」會發生什麼事：發起人失去一個月應變時間，而且一個月後的紅燈會變成「你任內的問題」。引導到 [W-20](../practice/W-20-first-30-days.md) 的做法：黃燈、寫「接手後確認到」而不是「前任報錯」、先口頭再書面、給下次更新時間。

## 講師筆記

### 常見誤解與破解方式

| 誤解 | 破解方式 |
|---|---|
| 「我先把事情做好，權力自然會來」 | 問：「做好的事有誰知道？誰會因此更信任你？」引導到可信度是要被看見的 |
| 「說不知道會失去權威」 | 反問：「一個從不說不知道的 PM，他說知道的時候你信嗎？」 |
| 「新人要低調，前幾週不要報壞消息」 | 用 W-20 的邏輯：接手初期說「這是既有狀況」最便宜，拖過去就變成你的 |
| 「紅燈等於我失敗」 | 把紅燈重新定義為「正式的求援管道」，並問學員：如果你是主管，你希望幾時知道？ |
| 「會議紀錄要寫得很詳細」 | 給學員看一份三頁的逐字稿和一份半頁的「決定 / 行動 / 待定」，問哪一份會被讀 |

### 冷場時可以拋的問題

- 「你上一次在會議上說『我不確定』是什麼時候？說完發生了什麼事？」
- 「如果你的主管現在問你『專案什麼時候好』，你會給一個日期還是一個範圍？」
- 「你本週答應過的事，有幾件是沒評估就答應的？」
- 「你的團隊裡，誰最可能把壞消息藏到最後一刻？為什麼是他？」

### 時間分配

=== "15 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–2 分 | 開場提問：「你第一次帶人時最早犯的錯」（請一位有經驗的人先講） |
    | 2–8 分 | 講義重點 1、2、4：權力來源、冒牌者感、順便加一個 |
    | 8–12 分 | 討論題 2：每人實際說出那一句話 |
    | 12–15 分 | 收尾：五句替代的話，請學員抄下來 |

=== "45 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–5 分 | 開場與討論題 1 |
    | 5–15 分 | 講義重點 1–3：權力、冒牌者感、前 30 天 |
    | 15–23 分 | 討論題 2 角色扮演：一人當主管、一人當 PM，交換一次 |
    | 23–33 分 | 講義重點 4–6：範疇蔓延、壞消息、燈號；搭配 C-08 的決策點 |
    | 33–40 分 | 討論題 3，兩兩寫出第一份週報的前三行 |
    | 40–45 分 | 講義重點 7 與收尾：五句替代的話、課後作業 |
