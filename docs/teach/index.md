# 教學素材總覽

**給要用這本手冊教別人的人：每份教案都有講義重點、討論題、講師筆記，以及 15 分鐘與 45 分鐘兩種時間配置。**

```text
 一份教案的結構

 ┌─ 講義重點 5–7 點：發給學員或投影
 ├─ 討論題 3 題：附引導方向（點開看）
 └─ 講師筆記
     ├─ 常見誤解與破解方式
     ├─ 冷場時可以拋的問題
     ├─ 建議搭配的案例與練習
     └─ 15 / 45 分鐘時間分配
```

## 教案清單

| 教案 | 主要模組 | 適合對象 |
|---|---|---|
| [範疇蔓延與變更控制](lesson-scope-creep.md) | M3、M10 | 新任 PM、技術組長 |
| [利害關係人與影響力](lesson-stakeholders.md) | M0、M2 | 需要跨部門協調的人 |
| [風險管理與割接](lesson-risk-cutover.md) | M6、M7 | 負責基礎架構變更的 PM 與工程師 |
| [狀態報告與向上管理](lesson-reporting-managing-up.md) | M9 | 需要定期向主管報告的人 |

## 建議的教學順序

如果要開一系列課程，建議順序：

1. 利害關係人與影響力（先建立「人」的觀點）
2. 範疇蔓延與變更控制
3. 風險管理與割接
4. 狀態報告與向上管理

!!! tip "教學小提醒"
    - 案例頁的「反事實推演」最適合當作小組討論題，因為它沒有標準答案。
    - 學員分享自己的經驗時，不要評斷對錯，先問「當時你知道什麼？」
    - 所有教案中的例子都是通用情境；在內部授課時，可以換成學員熟悉的情境，但請不要把內部資訊放回公開網站。
