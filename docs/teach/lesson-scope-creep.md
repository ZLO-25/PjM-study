# 教案：範疇蔓延與變更控制

**對象：** 新任 PM、技術組長　**搭配單元：** [T-10](../theory/T-10-scope-creep.md)、[T-23](../theory/T-23-change-control.md)、[P-06](../psychology/P-06-saying-no.md)、[W-16](../practice/W-16-change-request.md)

```text
 本堂課的主線

 為什麼範疇會悄悄變大？
        │
        ▼
 「不」不是拒絕，是取捨
        │
        ▼
 變更控制：被看見、被評估、被決定、被記錄
        │
        ▼
 帶走一句話 + 一張表
```

## 講義重點

1. **範疇蔓延的定義**：不是範疇變大，而是「沒有經過決策就變大」。
2. **常見來源**：走廊上的口頭要求、團隊自己的鍍金、模糊的需求被各自解讀。
3. **取捨三角**：範疇、時程、成本，動一個，其他至少要動一個，否則被犧牲的是品質。
4. **變更控制的四個動作**：被看見（提出請求）→ 被評估（影響分析）→ 被決定（有權者核准）→ 被記錄（變更紀錄表）。
5. **分級處理**：小變更 PM 核准，大變更送發起人或委員會。流程的重量要和影響成比例。
6. **一句話工具**：「我先評估影響，明天給你兩個選項。」
7. **敏捷的版本**：容量固定、範疇彈性；加一個就要拿掉或延後另一個。

## 討論題

**1. 回想你參與過的專案，有沒有一個「只要兩天」的要求，最後花了遠超過兩天？當時是怎麼答應的？**

??? note "引導方向"
    讓學員說出具體經驗。追問：「答應的時候，誰知道代價？」「如果當時有變更紀錄，事後的檢討會有什麼不同？」引導到「問題不是答應，而是沒有人看見代價」。

**2. 如果組織文化是「主管說了就要做」，變更控制還有用嗎？**

??? note "引導方向"
    有用，但形式要調整。PM 不是去擋主管，而是讓主管看見代價：「可以做，但上線會延一週，或者要拿掉 X，您比較傾向哪一個？」多數主管在看到代價後會做出合理的選擇。也可以討論：事先和主管約好變更的分級標準。

**3. 嚴格的變更控制在什麼情況下反而有害？**

??? note "引導方向"
    探索型、研究型、原型階段的工作，變更就是學習的方式。另外，若所有小變更都要開委員會，大家會繞過流程。引導到「流程的重量要和影響成比例」。

## 講師筆記

### 常見誤解與破解方式

| 誤解 | 破解方式 |
|---|---|
| 「防止範疇蔓延 = 什麼都拒絕」 | 問學員：「如果一個需求真的很有價值，拒絕它對專案好嗎？」引導到「讓決定被正確做出」 |
| 「小事不用記錄」 | 用加總的方式示範：十個「小事」各兩天，加起來就是一個月 |
| 「變更流程是官僚」 | 區分「流程太重」與「沒有流程」兩種問題，並展示分級表 |
| 「敏捷不用管範疇」 | 敏捷管的是容量，範疇蔓延在敏捷中的樣子是「每個 Sprint 都塞爆」 |

### 冷場時可以拋的問題

- 「誰曾經在走廊上答應過一件事，後來很後悔？」
- 「如果你是那位提出需求的副理，你希望 PM 怎麼回應你？」
- 「你們團隊現在有沒有在做『不在原本計畫裡』的工作？是誰決定的？」

### 建議搭配的案例

- [C-01 Denver 機場行李系統](../cases/C-01-denver-airport-baggage.md)：範圍擴大、時程不變。
- [C-03 FBI Virtual Case File](../cases/C-03-fbi-virtual-case-file.md)：需求長期無法凍結。
- 練習：[引導練習：如何回應「順便加一個功能」](../exercises/guide-scope-creep.md)

### 時間分配

=== "15 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–3 分 | 開場提問：「只要兩天」的經驗 |
    | 3–8 分 | 講義重點 1、3、4、6 |
    | 8–13 分 | 兩人一組演練一句話工具 |
    | 13–15 分 | 收尾：帶走一句話 + 變更紀錄表範本 |

=== "45 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–5 分 | 開場提問與討論題 1 |
    | 5–15 分 | 講義重點 1–5 |
    | 15–25 分 | 案例：C-01 Denver，請學員找出範疇擴大的決策點 |
    | 25–35 分 | 分組做引導練習「順便加一個功能」的問題 4、5 |
    | 35–42 分 | 討論題 2 或 3 |
    | 42–45 分 | 收尾：講義重點 6、7 |
