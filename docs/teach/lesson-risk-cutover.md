# 教案：風險管理與割接

**對象：** 負責基礎架構變更的 PM 與工程師　**搭配單元：** [T-15](../theory/T-15-risk-management.md)、[T-16](../theory/T-16-risk-issue-assumption.md)、[P-08](../psychology/P-08-escalation-of-commitment.md)、[W-08](../practice/W-08-risk-register.md)、[W-11](../practice/W-11-cutover-rollback.md)

```text
 本堂課的主線

 風險怎麼寫？（因為…可能…導致…）
        │
        ▼
 怎麼回應？（規避 / 轉移 / 減輕 / 接受）
        │
        ▼
 什麼時候行動？（觸發條件）
        │
        ▼
 割接：回退決策點 = 窗口 − 回退時間
```

## 講義重點

1. **風險 vs. 議題 vs. 假設**：可能發生、已經發生、當作真的。
2. **風險句型**：「因為〔原因〕，可能〔事件〕，導致〔影響〕。」
3. **四種回應策略**：規避、轉移、減輕、接受，各有成本。
4. **觸發條件與負責人**：沒有觸發條件的風險，通常拖到太晚才處理。
5. **回退決策點的計算**：最晚決策點 = 窗口結束時間 − 回退實測時間 − 驗證緩衝。
6. **「再試一下」的心理**：割接中的承諾升級，用事先寫好的規則對抗。
7. **演練環境要接近生產**：否則演練會給錯誤的信心。

## 討論題

**1. 你們的風險登錄表上次被打開是什麼時候？**

??? note "引導方向"
    很多團隊的答案是「啟動會議之後就沒看過」。追問：「那它在幫你們做什麼？」引導到風險管理的價值在定期檢視與執行回應，並提出「週會固定 5 分鐘」的做法。

**2. 割接進行到一半，最資深的工程師說「再 20 分鐘就好」，但已經到了回退決策點。你會怎麼做？**

??? note "引導方向"
    讓學員表達真實的掙扎：尊重資深者、不想白費工夫。然後計算延後 20 分鐘的後果。引導到「決策點是事先替現場的我們做決定」，以及「回退不是失敗」。可以搭配 C-08 案例。

**3. 什麼樣的風險值得花大錢規避？什麼樣的風險接受就好？**

??? note "引導方向"
    比較預期損失（機率 × 影響）與回應成本。舉例：影響營業的核心設備 vs. 實驗室設備。也要提到「影響極大但機率很低」的風險，需要的可能是應變計畫而不是規避。

## 講師筆記

### 常見誤解與破解方式

| 誤解 | 破解方式 |
|---|---|
| 「風險就是會出事的事」 | 用時態區分：已經出事的是議題，要用不同方式處理 |
| 「回退方案寫『還原設定』就好」 | 請學員估算在凌晨三點、壓力下，照這一行字操作需要多久 |
| 「回退 = 割接失敗」 | 重新定義：依規則回退是成功的風險管理 |
| 「有經驗就不用演練」 | 用 C-08 案例：實驗室規模不足導致問題沒被觸發 |

### 冷場時可以拋的問題

- 「誰有過割接超時的經驗？當時是怎麼決定繼續或回退的？」
- 「你們的回退方案有被實際演練過嗎？花了多久？」
- 「如果割接指揮官本人斷線了，誰接手？」

### 建議搭配的案例

- [C-08【模擬】核心網路割接](../cases/C-08-sim-network-cutover.md)：回退決策點的實際運作。
- [C-07【模擬】資料中心遷移](../cases/C-07-sim-datacenter-migration.md)：未驗證的假設。
- [C-01 Denver 機場行李系統](../cases/C-01-denver-airport-baggage.md)：高度創新技術的風險。

### 時間分配

=== "15 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–3 分 | 開場提問：割接超時的經驗 |
    | 3–9 分 | 講義重點 2、3、5 |
    | 9–13 分 | 現場計算：4 小時窗口、回退 1.5 小時，決策點在哪？ |
    | 13–15 分 | 收尾：講義重點 6 |

=== "45 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–5 分 | 開場與討論題 1 |
    | 5–15 分 | 講義重點 1–4 |
    | 15–22 分 | 每人用風險句型改寫自己專案的三個風險 |
    | 22–32 分 | 案例：C-08，分組扮演指揮官與資深工程師 |
    | 32–40 分 | 講義重點 5–7 + 討論題 2 |
    | 40–45 分 | 收尾，並發下自我檢核作為課後作業 |
