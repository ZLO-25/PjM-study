# 教案：利害關係人與影響力

**對象：** 新任 PM、需要跨部門協調的工程師　**搭配單元：** [T-06](../theory/T-06-stakeholder-analysis.md)、[T-07](../theory/T-07-stakeholder-engagement.md)、[P-01](../psychology/P-01-stakeholder-motives.md)、[P-03](../psychology/P-03-influence-without-authority.md)、[W-02](../practice/W-02-stakeholder-register.md)

```text
 本堂課的主線

 誰會影響專案？（識別）
        │
        ▼
 誰最重要？（權力 / 利益方格）
        │
        ▼
 他們真正在乎什麼？（立場 vs. 利益 vs. 恐懼）
        │
        ▼
 沒有職權時怎麼影響他們？（交換）
```

## 講義重點

1. **定義**：會影響專案、或會被專案影響的任何人或群體，不只是會議上的人。
2. **五個掃描問題**：誰付錢、誰被改變、誰要維運、誰能喊停、誰提供資源。
3. **權力 / 利益方格**：四個象限決定花多少心力；特別注意「權力高、目前利益低」的人。
4. **冰山模型**：立場是說出口的，利益要追問，恐懼通常不會說出口。
5. **參與度落差**：現在的態度 vs. 需要的態度，落差最大的人最值得投入。
6. **影響力交換**：先了解對方在乎什麼，再提供對方重視的「貨幣」（資訊、協助、認可、參與）。
7. **重要會議上不該有驚喜**：關鍵決策前，先一對一確認立場。

## 討論題

**1. 你的專案中，誰是那個「平常不說話、但最後一刻可以喊停」的人？**

??? note "引導方向"
    常見答案：資安、稽核、法務、維運主管。追問：「你什麼時候第一次讓他看到專案的設計？」引導到「越早讓他參與，越少最後一刻的驚喜」。

**2. 一位主管強烈反對你的方案，你覺得他「就是不想配合」。有沒有其他可能的解釋？**

??? note "引導方向"
    用冰山模型，請學員至少想出三種可能的利益或恐懼：怕增加工作量、怕出事被追究、上次類似的改變很痛苦、覺得沒被尊重。引導到「反對者常常是資訊來源」。

**3. 「先給再要」聽起來很好，但如果對方一直拿不回報呢？**

??? note "引導方向"
    討論關係帳戶的概念：不是每次都要等價交換，而是長期的信任。但如果持續單向付出，可以把對話轉向共同目標，或在必要時透過正式管道（職能經理、升級）處理。不要讓學員以為影響力等於無限讓步。

## 講師筆記

### 常見誤解與破解方式

| 誤解 | 破解方式 |
|---|---|
| 「利害關係人管理 = 寄更多信」 | 問：「你寄了十封信，對方的顧慮有被處理嗎？」 |
| 「影響力 = 操弄」 | 區分公開的交換與隱藏意圖；問「對方事後知道了，會覺得被騙嗎？」 |
| 「權力高的人才重要」 | 用維運值班人員的例子：個別權力低，但集體可以讓上線失敗 |
| 「把方格表貼給大家看」 | 提醒敏感資訊的處理：對外的登錄表只寫中性描述 |

### 冷場時可以拋的問題

- 「誰曾經在上線前一週才知道某個部門反對？」
- 「你最常需要但不歸你管的人是誰？你能給他什麼？」
- 「如果你的方案讓某個人的專長變得不重要，他會怎麼反應？」

### 建議搭配的案例

- [C-10【模擬】跨廠區建置](../cases/C-10-sim-multi-site-buildout.md)：三位廠區主管的不同態度。
- [C-09【模擬】老舊系統汰換](../cases/C-09-sim-legacy-replacement.md)：抗拒者變成推廣者。
- 練習：[引導練習：如何處理一個抗拒的利害關係人](../exercises/guide-resistant-stakeholder.md)

### 時間分配

=== "15 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–3 分 | 開場提問：「上線前一週才知道某部門反對」 |
    | 3–9 分 | 講義重點 2、3、4 |
    | 9–13 分 | 每人用五個掃描問題列出自己專案的利害關係人 |
    | 13–15 分 | 收尾：講義重點 7 |

=== "45 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–5 分 | 開場提問與討論題 1 |
    | 5–15 分 | 講義重點 1–5 |
    | 15–25 分 | 每人畫自己專案的權力 / 利益方格，兩人互相挑錯 |
    | 25–35 分 | 案例：C-10，分組討論 PM 在第 8 週的選擇 |
    | 35–42 分 | 講義重點 6 + 討論題 2 |
    | 42–45 分 | 收尾：講義重點 7 |
