# 教案：狀態報告與向上管理

**對象：** 新任 PM、需要定期向主管報告的組長　**搭配單元：** [T-22](../theory/T-22-status-reporting.md)、[P-05](../psychology/P-05-managing-up.md)、[P-15](../psychology/P-15-mum-effect.md)、[W-14](../practice/W-14-status-report.md)、[W-15](../practice/W-15-escalation.md)

```text
 本堂課的主線

 為什麼壞消息總是太晚？（緘默效應）
        │
        ▼
 燈號要有定義，紅燈是求援
        │
        ▼
 結論先行：需要您決定的是…
        │
        ▼
 沒有驚喜：先口頭、再書面
```

## 講義重點

1. **西瓜報表**：外面綠、裡面紅；問題早就存在，只是沒有反映在報告上。
2. **緘默效應**：人天生不願意傳遞壞消息，每經過一層就被淡化一點。
3. **燈號定義**：綠 = 不需介入；黃 = 有偏差、PM 有對策；紅 = 需要上級決策或協助。
4. **紅燈是求援的正式管道**，不是失敗的宣告。
5. **結論先行**：第一句就說「需要您決定的是…」或「本期無需決策」。
6. **主管最怕三件事**：驚喜、沒選項、不知道要他做什麼。
7. **感謝帶來壞消息的人**：PM 的反應決定了團隊下次會不會說。

## 討論題

**1. 你曾經在報告中把一個問題寫得「比實際輕一點」嗎？當時為什麼？**

??? note "引導方向"
    營造安全的氛圍，講師可以先分享自己的例子。常見理由：想自己先解決、怕被罵、不確定嚴重程度。引導到「這些理由都很正常，但要靠規則和習慣來克服，而不是靠意志力」。

**2. 如果你的主管一聽到壞消息就發脾氣，你還要早點講嗎？要怎麼講？**

??? note "引導方向"
    還是要講，但要調整方式：帶著選項與建議、先講影響範圍與對策、選擇合適的時機。也可以討論：和主管事先約定「哪些事我會在 24 小時內告訴您」，讓報告變成約定好的規則。

**3. 「需要您決定的事」放在週報最上面，有什麼風險？**

??? note "引導方向"
    可能讓主管覺得你什麼都要問。區分「需要決策」與「告知」，並和主管約定授權範圍。也可以討論：如果連續很多週都有決策需求，可能代表授權太少，或專案問題很多。

## 講師筆記

### 常見誤解與破解方式

| 誤解 | 破解方式 |
|---|---|
| 「報黃燈會被追問，報綠燈比較輕鬆」 | 問：「你寧可現在被追問，還是一個月後被問『為什麼現在才說』？」 |
| 「寄了週報就是溝通了」 | 寄出不等於讀了、讀懂了；重要的壞消息先口頭講 |
| 「向上管理 = 拍馬屁」 | 向上管理是讓主管做出好決定，有時意味著說他不想聽的話 |
| 「要等有解法再報告」 | 「問題 + 處理中 + 何時更新」本身就是有價值的資訊 |

### 冷場時可以拋的問題

- 「你最近一次從別人口中聽到你自己專案的壞消息，是什麼感覺？」
- 「你的主管喜歡看數字還是聽故事？書面還是口頭？」
- 「如果你的週報只能留一句話，你會留哪一句？」

### 時間分配

=== "15 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–3 分 | 開場：畫出西瓜報表的五週燈號 |
    | 3–9 分 | 講義重點 2、3、5、6 |
    | 9–13 分 | 每人把自己的週報第一句改寫成「需要您決定的是…」 |
    | 13–15 分 | 收尾：講義重點 7 |

=== "45 分鐘版"

    | 時間 | 內容 |
    |---|---|
    | 0–5 分 | 開場與討論題 1 |
    | 5–15 分 | 講義重點 1–4 |
    | 15–25 分 | 分組做引導練習「如何回報一個壞消息」的問題 3–5 |
    | 25–35 分 | 角色扮演：一人當主管、一人當 PM，演練口頭報告 |
    | 35–42 分 | 講義重點 5–7 + 討論題 2 |
    | 42–45 分 | 收尾，並發下週報範本 |
