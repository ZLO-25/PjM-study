# 實作 (W)

**實作單元提供範本、步驟與範例，讓你明天上班就能用。不知道該用哪一個？看「什麼時候用」那一欄，或直接去 [遇到問題查這裡](../troubleshoot.md)。**

```text
 一個專案會用到的工具，大致照時間順序

 啟動      W-20 → W-01 → W-02 → W-13
 規劃      W-03 → W-04 → W-05 → W-06 → W-07 → W-08
 執行追蹤  W-09 → W-21 → W-14 → W-12
 出狀況時  W-15 → W-16
 交付      W-10 → W-11
 收尾      W-18 → W-19
 做法設計  W-17（任何階段都可能用到）
```
