# T-04 商業論證與效益 (Business Case & Benefits)

**商業論證回答「為什麼這件事值得花這些錢和時間做」，而且它不是開工前寫完就丟的文件，而是整個專案期間反覆檢查「還值得嗎」的依據。**

```text
 問題或機會
    │
    ▼
 可行方案 ─┬─ 方案 A：什麼都不做（基準）
           ├─ 方案 B
           └─ 方案 C
    │
    ▼ 比較：成本、效益、風險、時程
 建議方案 ──► 核准 ──► 專案章程 (T-05)
    │
    └──► 每個階段關卡重新檢查：「還值得嗎？」
```

=== "入門"

    **白話解釋**

    一份商業論證通常包含：

    1. **要解決的問題或掌握的機會**：用業務語言寫，不是技術語言。
    2. **方案比較**：至少要有「什麼都不做」當基準，讓人看出做與不做的差別。
    3. **成本**：一次性投入與後續維運成本。
    4. **效益**：可量化的（省多少錢、降多少故障時間）和不易量化的（降低稽核風險）。
    5. **風險與假設**：這個論證在什麼條件下會不成立。
    6. **建議與決策需求**：你要決策者決定什麼。

    **IT 例子**

    技術說法：「核心交換器已到 EoS（停止支援），需要汰換。」
    業務說法：「現有設備原廠不再提供安全更新與備品。一旦故障，修復時間無法保證，可能影響生產系統。汰換成本為 X；不汰換的話，我們要承擔的是無法估計的停機風險，以及稽核時的不合規項目。」

    後者讓不懂網路的決策者也能判斷。

    **最常見的誤解**

    「商業論證是業務部門的事，技術 PM 不用管。」實際上很多 IT 基礎架構專案的效益是「避免損失」，只有技術 PM 說得清楚風險的樣貌，不寫就沒人能替你寫好。

=== "進階"

    **取捨與兩難**

    - **樂觀的論證比較容易通過**，但也會讓專案一開始就背著達不到的承諾，見 [P-07 規劃謬誤與樂觀偏誤](../psychology/P-07-planning-fallacy.md)。
    - **效益常在專案結束後才發生**。專案經理交付了成果，效益卻要由營運單位實現；誰負責追蹤效益，必須一開始就說清楚。
    - 論證寫得越精確，越容易被當成承諾。資深 PM 會寫出**範圍**（樂觀/可能/悲觀）而不是單一數字。

    **跨主題的互動**

    - 專案進行中，如果成本或效益的假設已經不成立，應該在 [T-24 治理與階段關卡](T-24-governance-stage-gates.md) 重新決定是否繼續。
    - 「已經花了這麼多，不能停」是典型的 [P-08 沉沒成本與承諾升級](../psychology/P-08-escalation-of-commitment.md)：決定繼續與否要看「未來的成本與效益」，不是已花掉的錢。

    **資深 PM 怎麼判斷**

    問自己：「如果明天決策者問我『這個專案現在停掉會怎樣』，我答得出來嗎？」答得出來，代表你仍然掌握這個專案的商業理由。

## 明天上班可以怎麼用

- 用三句話寫下你目前專案的商業理由：解決什麼問題、不做會怎樣、做了得到什麼。
- 找出商業論證裡最關鍵的一個假設（例如「新系統能減少 30% 人工作業」），把它放進風險登錄表定期檢查，見 [W-08 風險登錄表](../practice/W-08-risk-register.md)。
- 下次提案時，一定加上「什麼都不做」這個選項。

## 對照案例

- [C-05 Berlin Brandenburg 機場](../cases/C-05-berlin-brandenburg-airport.md)：成本與時程一再超出原始論證時，「要不要繼續」的判斷如何被政治壓力影響。
- [C-06 英國 NHS NPfIT](../cases/C-06-nhs-npfit.md)：效益不明確、由上而下推動的大型計畫。

## 小測驗

你的專案進行到一半，發現原本商業論證中「新系統可減少兩名人力」的假設已經不成立（業務單位改了流程）。成本則照原計畫。你應該？

- A. 繼續執行，因為已經核准，而且已經花了一半預算
- B. 不讓別人知道，等結案後再說
- C. 把假設改變與影響整理出來，提交給發起人與治理單位，讓他們決定是否繼續、調整或停止
- D. 自行縮小範疇，把預算省下來

??? success "看答案與解析"
    **答案是 C。**

    - **A 錯：** 「已經花了一半」是沉沒成本，不該影響「繼續是否值得」的判斷，見 [P-08 沉沒成本與承諾升級](../psychology/P-08-escalation-of-commitment.md)。
    - **B 錯：** 隱瞞讓決策者在錯誤資訊下繼續投資，是 PM 最嚴重的失職之一，見 [P-15 壞消息上報延遲](../psychology/P-15-mum-effect.md)。
    - **C 對：** 商業論證是持續有效的決策依據。假設改變時，PM 的責任是讓有權者重新決定，見 [T-24 治理與階段關卡](T-24-governance-stage-gates.md)。
    - **D 錯：** 縮小範疇是發起人的決定，不是 PM 自己的決定，見 [T-23 整合變更控制](T-23-change-control.md)。
