# T-15 風險管理 (Risk Management)

**風險是「還沒發生、但如果發生會影響專案目標」的不確定事件；風險管理就是提早找出它們、判斷哪些最值得處理，並在它們發生前準備好行動。**

```text
 識別 ──► 分析 ──► 規劃回應 ──► 執行與監控
  │        │          │              │
  │        │          │              └─ 定期重新檢視
  │        │          └─ 威脅：規避 / 轉移 / 減輕 / 接受
  │        │             機會：利用 / 分享 / 強化 / 接受
  │        └─ 機率 × 影響
  └─ 寫成「因為…可能…導致…」

 機率 × 影響矩陣
          影響 →  低     中     高
 機率 高         中     高     高
      中         低     中     高
      低         低     低     中
```

=== "入門"

    **白話解釋**

    **寫風險的句型**：「因為〔原因〕，可能發生〔事件〕，導致〔對目標的影響〕。」
    例如：「因為新型號交換器剛上市，可能出現韌體缺陷，導致割接後需要回退、延誤上線兩週。」

    **四種回應威脅的策略**

    | 策略 | 意思 | IT 例子 |
    |---|---|---|
    | 規避 Avoid | 改變計畫，讓風險不可能發生 | 改用已有穩定版本的型號 |
    | 轉移 Transfer | 把影響轉給第三方 | 合約要求原廠駐點支援 |
    | 減輕 Mitigate | 降低機率或影響 | 先在測試環境跑兩週 |
    | 接受 Accept | 不主動處理，但準備應變 | 預留回退時間與預算 |

    風險也可能是正面的（機會），例如「新設備可能提早到貨，讓我們能多一輪測試」。

    **最常見的誤解**

    「風險登錄表填完就好。」很多專案的風險表在啟動會議後就沒人再打開過。風險管理的價值在**定期檢視**和**執行回應**，不在表格本身。

=== "進階"

    **取捨與兩難**

    - 每一個回應都有成本。為一個機率很低的風險花大錢規避，可能不划算。判斷依據是「預期損失」與「回應成本」的比較。
    - **【敏捷】** 透過短迭代和頻繁交付降低風險：越早做出能動的東西，越早暴露問題。但這不代表不需要風險登錄表，外部相依、合約、合規風險仍需要追蹤。
    - **什麼時候不適用繁重的風險流程**：小型、低影響、可輕易回復的工作，一張簡單清單就夠。

    **跨主題的互動**

    - 風險發生了就變成議題，兩者的差異見 [T-16 風險、議題與假設](T-16-risk-issue-assumption.md)。
    - 人容易低估壞事發生的機率，見 [P-07 規劃謬誤與樂觀偏誤](../psychology/P-07-planning-fallacy.md)；團隊太一致時容易看不見風險，見 [P-14 團體迷思](../psychology/P-14-groupthink.md)。

    **資深 PM 怎麼判斷**

    資深 PM 會為每個高風險指定一個**觸發條件**（Trigger）和**負責人**。例如「如果到第 6 週測試仍未通過，就啟動備案」。沒有觸發條件的風險，通常會拖到太晚才處理。

## 明天上班可以怎麼用

- 用「因為…可能…導致…」改寫你風險表中的前五項。
- 對每個高風險指定一個負責人和一個觸發條件。
- 在週會固定留 5 分鐘：「有沒有新的風險？有沒有風險已經變成議題？」
- 工具見 [W-08 風險登錄表](../practice/W-08-risk-register.md)、[W-11 割接計畫與回退方案](../practice/W-11-cutover-rollback.md)。

## 小測驗

你的專案依賴一款新型號防火牆。原廠表示新韌體「應該」會在下個月釋出，修正一個已知問題。下列哪一項是**減輕 (Mitigate)** 策略？

- A. 改用上一代、已穩定的型號
- B. 在合約中要求原廠若延誤需負擔賠償
- C. 提前在測試環境驗證現有韌體，找出可繞過的設定方式，降低問題影響
- D. 什麼都不做，等韌體釋出

??? success "看答案與解析"
    **答案是 C。**

    - **A 錯：** 這是**規避**，直接移除了風險來源。
    - **B 錯：** 這是**轉移**，把財務影響轉給原廠，但風險本身仍可能發生。
    - **C 對：** 降低風險發生時的影響，是**減輕**。
    - **D 錯：** 這是消極的接受，而且沒有應變準備。積極的接受至少要預留時間與預算，見 [W-08 風險登錄表](../practice/W-08-risk-register.md)。
