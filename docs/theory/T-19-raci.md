# T-19 責任分派與 RACI (Responsibility Assignment)

**RACI 矩陣把每一項工作或決策對應到四種角色：誰執行 (R)、誰當責 (A)、誰要被諮詢 (C)、誰要被告知 (I)；它的目的是讓「這件事是誰的」不再需要猜。**

```text
 工作項目          PM   網路   資安   維運   發起人
 ──────────        ──   ────   ────   ────   ──────
 架構設計          C    A/R    C      C      I
 防火牆規則        I    R      A      I      ─
 割接計畫          A    R      C      C      I
 上線決策          R    C      C      C      A
 移交維運          A    R      I      C      I

 R 執行 Responsible：實際動手做
 A 當責 Accountable：最終負責，每列只能一個
 C 諮詢 Consulted：事前要問，雙向溝通
 I 告知 Informed：事後通知，單向溝通
```

=== "入門"

    **白話解釋**

    RACI 的基本規則：

    1. **每一列只能有一個 A**。兩個人都當責，等於沒人當責。
    2. **每一列至少要有一個 R**。沒人執行的工作不會自己完成。
    3. **C 不要太多**。每多一個 C，就多一個要等的人。
    4. A 和 R 可以是同一人。

    **IT 例子**

    上表中「防火牆規則」的 A 是資安、R 是網路。意思是網路團隊動手設定，但規則是否合規，由資安最終負責。如果沒有講清楚，常見情況是網路團隊以為資安會審、資安以為網路團隊會自己檢查，結果沒人審。

    **最常見的誤解**

    「RACI 是為了出事時找人負責。」RACI 的目的是**事前**避免責任真空和重複工作，不是事後追究。如果團隊把它當成卸責工具，大家就會想辦法不被寫成 A。

=== "進階"

    **取捨與兩難**

    - RACI 列得太細，維護成本高，沒人會看；列得太粗，關鍵決策還是不清楚。重點放在**跨團隊交界處**和**決策**，團隊內部的分工可以交給團隊自己。
    - 在矩陣式組織中，A 有時要由職能經理擔任，而非 PM。這反映了 PM 的權力邊界，見 [T-20 矩陣式組織](T-20-matrix-organization.md)。
    - **【敏捷】** 團隊通常較少用 RACI，因為團隊是自組織的；但對外部的介面（例如資安審查、上線核准）仍然適用。

    **跨主題的互動**

    - 責任模糊是衝突的常見來源，見 [P-13 衝突處理模式](../psychology/P-13-conflict-modes.md)。
    - 團隊剛組成時，用 RACI 對齊角色能加速度過磨合期，見 [P-12 團隊發展階段](../psychology/P-12-team-development-stages.md)。

    **資深 PM 怎麼判斷**

    資深 PM 會把 RACI 草稿拿到啟動會議上讓大家「挑錯」。如果沒有人提出異議，通常代表大家沒認真看；如果有人說「這個 A 不應該是我」，恰好是提早解決問題的機會。

## 明天上班可以怎麼用

- 挑你專案中最常發生「以為對方會做」的三件事，畫一張小 RACI。
- 檢查每一列是否只有一個 A。
- 把重要決策（上線、變更核准、驗收）也列進 RACI，不只列工作項目。
- 練習見 [W-12 填一張 RACI](../practice/W-12-raci-matrix.md)。

## 小測驗

在一張 RACI 中，「上線決策」這一列寫著：PM = A、維運主管 = A、發起人 = A。這會造成什麼問題？

- A. 沒問題，大家一起負責比較安全
- B. 當責者太多，決策時可能互相等待或互相推託，最後沒人真正拍板
- C. 只是格式問題，不影響實際運作
- D. 應該把所有人都改成 R

??? success "看答案與解析"
    **答案是 B。**

    - **A 錯：** 「大家一起負責」實際上常變成「沒人負責」。這種情況下，有事時每個人都會等別人先決定。
    - **B 對：** 每一列只能有一個 A。上線決策通常由發起人或業務負責人當責，PM 負責準備資訊 (R)，維運主管提供意見 (C)。
    - **C 錯：** RACI 的價值就在於釐清這個問題，格式錯誤就是實際的責任錯誤。
    - **D 錯：** 全部改成 R 仍然沒有當責者。
