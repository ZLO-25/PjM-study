# C-04 Sydney 歌劇院 (Sydney Opera House)

**一句話摘要：一座在設計還沒完成時就開工的建築，最終比原定晚了十年完工、成本超出原始估算十倍以上，卻也成為世界知名的地標；它同時是成本失控與「成果價值」兩個議題的經典教材。**

!!! note "閱讀說明"
    本頁區分「已知事實」與「推論詮釋」。成本與時程數字以澳洲官方資料與常被引用的研究為準；不同資料對金額的計算方式可能不同（例如是否計入通膨）。

```text
 原計畫 vs. 實際（概略）

            原計畫              實際
 ─────────  ─────────          ─────────
 完工        1963 年左右        1973 年
 成本        約 700 萬澳元      約 1.02 億澳元

 時間線
 1957  國際設計競賽，選出得獎設計
   │
 1959  在設計尚未完成時開工
   │
 1960s 屋頂殼體結構的工程方法反覆研究
   │   建築師與政府關係惡化
   │
 1966  原建築師辭職，由其他團隊接手完成
   │
 1973  正式啟用
```

## 背景

=== "已知事實"

    - 新南威爾斯州政府在 1957 年透過國際競賽選出設計，得獎者是一位丹麥建築師。
    - 工程在 1959 年開工，當時屋頂殼體的結構工程方法尚未解決，內部設計也未完成。
    - 屋頂殼體的幾何與施工方法經過多年研究才確定，部分已完成的基礎工程後來需要調整。
    - 1966 年，因設計、成本與付款等爭議，原建築師在與新上任的州政府爭執後辭職，之後由其他團隊完成內部設計。
    - 歌劇院於 1973 年啟用。常被引用的數字是：原估算約 700 萬澳元，最終成本約 1.02 億澳元。
    - 建設經費有相當部分來自專為此設立的彩券。
    - 2007 年被列為聯合國教科文組織世界遺產。

=== "推論詮釋"

    - 開工時間可能受到政治因素影響（希望在政治時程內看到進度），導致設計未完成就動工。這是常見的詮釋，但具體動機的程度不易確定。
    - 研究大型專案的學者 Flyvbjerg 常以此案說明大型專案中的樂觀偏誤與成本超支。

## 關鍵決策點

1. **在設計與工程方法未確定前開工**。
2. **公開早期的成本估算**，成為之後的錨點。
3. **建築師與業主之間的權責與溝通**，最終導致建築師離開。

## 出了什麼事

- **已知**：時程延後約十年，成本大幅超支。
- **已知**：原建築師離開後，內部設計由其他團隊完成，與原始構想有差異。
- **推論**：早期估算是在資訊極度不足的情況下做出的，卻被當成承諾，這讓後續的每一次調整都被視為「失控」。

## 反事實推演

- **分階段核准**：先核准設計與工程研究階段的預算，等殼體工法確定後，再核准建造預算。
- **以範圍報告估算**：公開時說明「目前估算的不確定性很高，設計完成後會更新」。
- **明確的權責與溝通機制**：建築師、工程師與業主之間有定期的決策會議與變更流程。

## 可帶走的教訓

1. **設計未完成就開工，等於在最不確定的時候做最昂貴的承諾。**
2. **早期估算要給範圍、說明假設**，並約定何時更新。
3. **「成功」的定義要包含效益**：同樣一座建築，以專案管理指標看是失敗，以長期價值看卻可能是成功。這兩種觀點都值得討論。

## 小測驗

有人說：「歌劇院現在是世界地標，所以當初的超支不重要。」用專案管理的角度，最平衡的看法是？

- A. 完全同意，結果好就好
- B. 完全不同意，超支就是失敗
- C. 專案的交付績效（時程、成本）和產品的長期效益是兩個不同的問題；本案在前者表現很差，在後者表現很好，兩者都值得學習
- D. 這只是建築專案，和 IT 無關

??? success "看答案與解析"
    **答案是 C。**

    - **A 錯：** 以結果論忽略了過程中的浪費與風險；許多同樣超支的專案並沒有成為地標。這也是一種倖存者偏差。
    - **B 錯：** 只看時程與成本，忽略了專案存在的目的是創造效益，見 [T-04 商業論證與效益](../theory/T-04-business-case.md)。
    - **C 對：** 區分「專案管理績效」與「效益實現」，是 [T-01 專案、專案集與產品](../theory/T-01-project-program-product.md) 中專案與產品觀點的差別。
    - **D 錯：** 在設計未定時開工、早期估算被當成承諾，在 IT 專案中同樣常見。
