# P-12 團隊發展階段 (Stages of Team Development)

**團隊從組成到高效運作，通常會經歷形成、風暴、規範、表現等階段；知道團隊在哪個階段，PM 就知道該用什麼方式帶領。**

```text
 Tuckman 團隊發展模型

 表現
  高 │                             ╭── 表現
     │                           ╱    Performing
     │                 規範 ────╯
     │                Norming
     │     形成    ╱
     │   Forming ╲  ╱
  低 │            ╰─ 風暴 Storming
     └──────────────────────────────────► 時間
                                    └► 解散 Adjourning

 PM 的角色隨階段改變
 形成 → 指導：說清楚目標與角色
 風暴 → 教練：處理衝突、釐清分工
 規範 → 支持：鞏固工作方式
 表現 → 授權：退後一步，排除外部障礙
```

=== "入門"

    **白話解釋**

    這個模型由 Bruce Tuckman 在 1965 年提出前四階段，1977 年與 Mary Ann Jensen 補上「解散」階段。

    | 階段 | 團隊樣貌 | 常見訊號 |
    |---|---|---|
    | 形成 Forming | 客氣、觀望、依賴 PM | 會議安靜、等待指示 |
    | 風暴 Storming | 對做法、角色有分歧 | 爭論、抱怨、推託 |
    | 規範 Norming | 建立共同做法 | 開始互相支援 |
    | 表現 Performing | 自主運作、效率高 | PM 不在也能運作 |
    | 解散 Adjourning | 專案結束 | 不捨或焦慮下一步 |

    **IT 例子**

    跨部門的機房遷移團隊剛組成時，網路、系統、應用三個團隊各自為政（形成）。第一次演練失敗後，開始互相指責是誰的問題（風暴）。PM 引導大家一起訂出交接規則與 RACI（規範）。到了第三次演練，各團隊主動協調時程，PM 只需處理外部協調（表現）。

    **最常見的誤解**

    「風暴期代表團隊有問題。」風暴是正常的，甚至是必要的。完全沒有風暴的團隊，可能是大家都在壓抑不同意見，見 [P-14 團體迷思](P-14-groupthink.md)。

=== "進階"

    **取捨與兩難**

    - 團隊不一定線性前進。新成員加入、目標改變、重大挫折，都可能讓團隊退回風暴期。
    - 專案團隊的生命週期通常很短，可能還沒走到表現階段就結束了。PM 可以用啟動會議、RACI、工作協議加速度過前兩個階段。
    - 這個模型是幫助理解的框架，研究上對其普遍性仍有討論；把它當作觀察工具，而不是預測公式。

    **跨主題的互動**

    - 啟動會議能加速形成期，見 [W-13 專案啟動會議](../practice/W-13-kickoff-meeting.md)。
    - 風暴期的衝突處理見 [P-13 衝突處理模式](P-13-conflict-modes.md)。
    - 角色釐清見 [T-19 責任分派與 RACI](../theory/T-19-raci.md)。

    **資深 PM 怎麼判斷**

    資深 PM 在風暴期最常犯的錯是「太早滅火」：一有爭論就介入裁決。適度的爭論能讓團隊找到更好的做法，PM 要做的是確保爭論對事不對人，並在必要時才收斂。

## 明天上班可以怎麼用

- 判斷你的團隊目前在哪個階段，寫下一個支持你判斷的訊號。
- 如果在形成期：在下次會議上再說一次目標、角色、決策方式。
- 如果在風暴期：找出爭論的核心，用 RACI 或工作協議把它寫清楚。
- 如果在表現期：檢查自己是不是管太多了。

## 小測驗

專案進行到第三週，團隊成員開始為「誰負責防火牆設定」爭論，會議氣氛緊張。這最可能是哪個階段？PM 該做什麼？

- A. 形成期；PM 應該等大家熟悉後再處理
- B. 風暴期；PM 應該引導大家釐清角色與責任，例如一起完成 RACI，把爭論轉成共同規則
- C. 表現期；PM 不需要介入
- D. 解散期；團隊即將解散

??? success "看答案與解析"
    **答案是 B。**

    - **A 錯：** 形成期的特徵是客氣、觀望，不是公開爭論。
    - **B 對：** 對角色與做法的爭論是風暴期的典型。PM 要以教練角色引導，把衝突轉成明確的規範，見 [T-19 責任分派與 RACI](../theory/T-19-raci.md)。
    - **C 錯：** 表現期的團隊已經有共同規則，不會為基本分工爭論。
    - **D 錯：** 專案才第三週，與解散無關。
