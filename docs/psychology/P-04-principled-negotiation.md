# P-04 原則式談判與 BATNA (Principled Negotiation & BATNA)

**原則式談判主張把人和問題分開、聚焦在利益而不是立場、一起想出多個選項，再用客觀標準來決定；BATNA 是「如果談不成，你的最佳替代方案」，它決定了你在談判中的底氣。**

```text
 原則式談判的四個要點

 ┌─ 1. 人與問題分開：對事強硬，對人溫和
 ├─ 2. 利益而非立場：問「為什麼」
 ├─ 3. 創造多個選項：先發散，再收斂
 └─ 4. 客觀標準：用數據、慣例、規範決定

 BATNA 的位置

 你的 BATNA        協議區間        對方的 BATNA
     │◄──────── 可以成交 ────────►│
 ────┼────────────────────────────┼────
   你的底線                     對方的底線

 BATNA 越好 → 越不怕談不成 → 越有空間
```

=== "入門"

    **白話解釋**

    原則式談判出自哈佛談判專案 (Harvard Negotiation Project) 的研究，Fisher 與 Ury 的著作讓它廣為人知。

    - **立場**：「我要小陳全職三個月。」
    - **利益**：「我需要在第二季完成核心網路設定，小陳是唯一有經驗的人。」

    把立場拆成利益後，選項就多了：小陳可以兼任並帶一位新人、可以請原廠支援、可以把部分工作外包、可以調整時程避開他的忙碌期。

    **BATNA (Best Alternative to a Negotiated Agreement)**

    談判前一定要先想清楚：「如果對方不答應，我能怎麼辦？」例如「如果借不到小陳，我可以花 X 元請原廠工程師駐點兩週」。有了這個答案，你就知道什麼樣的條件值得接受、什麼樣的條件不如走 BATNA。

    **最常見的誤解**

    「談判就是討價還價，誰讓步比較少誰贏。」在組織內部，你和對方之後還要合作很多年。「贏」了這次卻毀了關係，長期來看是輸。

=== "進階"

    **取捨與兩難**

    - **改善 BATNA** 是談判前最值得花時間的事。例如和供應商談交期前，先詢問第二家供應商的報價與交期。
    - 不要輕易透露你的 BATNA，特別是在它不太好的時候。但也不要虛張聲勢，被識破後信用全失。
    - 組織內部談判常有「第三方」：雙方的主管。如果談不攏，升級上報也是一種 BATNA，但它有成本（關係、時間）。

    **跨主題的互動**

    - 了解對方利益的方法見 [P-01 利害關係人的動機與恐懼](P-01-stakeholder-motives.md)。
    - 借資源的情境見 [T-14 資源規劃與平衡](../theory/T-14-resource-planning.md)、[T-20 矩陣式組織](../theory/T-20-matrix-organization.md)。
    - 談判中的衝突風格見 [P-13 衝突處理模式](P-13-conflict-modes.md)。

    **資深 PM 怎麼判斷**

    資深 PM 談判前會準備一頁筆記：我的利益、對方可能的利益、三個以上的可能選項、可以引用的客觀標準、我的 BATNA、對方可能的 BATNA。準備十分鐘，談判效果差很多。

## 明天上班可以怎麼用

- 下一次要借人或要預算，先寫出你的 BATNA。
- 談判時至少問對方一次「這對你來說，最重要的是什麼？」
- 準備一個客觀標準，例如「原廠建議的施工時間」「上次類似專案的實際工時」。

## 小測驗

供應商通知設備會延誤四週。你準備和他們協商。談判前，最重要的準備工作是什麼？

- A. 準備好合約條款，準備追究違約責任
- B. 確認你的 BATNA：是否有其他供應商、現貨、租借設備或調整時程的選項，以及各自的代價
- C. 想好要用什麼語氣表達不滿
- D. 先請主管出面

??? success "看答案與解析"
    **答案是 B。**

    - **A 錯：** 合約條款是客觀標準之一，值得準備，但只靠追究責任，設備還是不會提早到。
    - **B 對：** 知道自己的替代方案，才知道什麼樣的協議值得接受，也讓你在談判中有底氣。
    - **C 錯：** 情緒表達對解決問題幫助有限，原則式談判強調把人和問題分開。
    - **D 錯：** 主管出面是一種升級，留到你自己談不攏時再用。
