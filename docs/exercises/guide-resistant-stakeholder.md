# 引導練習：如何處理一個抗拒的利害關係人

**情境：** 你負責導入新的網路存取控制 (NAC) 系統，所有連上公司網路的設備都要先通過認證。製造部門的主管在專案說明會上公開表示：「我們產線的設備不能接受任何新的認證機制，出了問題誰負責？」會議氣氛很僵。他的部門有上百台產線設備，沒有他的配合，專案無法完成。

**怎麼用這一頁：** 每一題先自己想，再點開提示與參考思路。

## 問題 1：他說的是「立場」還是「利益」？

??? tip "提示"
    「不能接受新的認證機制」是他要的東西，還是他要的東西背後的原因？

??? note "參考思路"
    「不能接受新機制」是**立場**。「出了問題誰負責」透露了他的**恐懼**：如果產線停線，他會被追究。他真正的**利益**可能是「產線持續穩定運作」。參考 [P-01 利害關係人的動機與恐懼](../psychology/P-01-stakeholder-motives.md)。

## 問題 2：在權力 / 利益方格中，他在哪裡？他的參與度現在是什麼、需要是什麼？

??? tip "提示"
    他能不能讓專案停下來？他在不在乎這個專案？

??? note "參考思路"
    權力高（他的配合是必要條件）、利益高（專案直接影響他的產線），屬於**重點管理**。參與度目前是**抗拒**，專案需要他至少**支持**。落差很大，值得投入時間。參考 [T-06 利害關係人識別與分析](../theory/T-06-stakeholder-analysis.md)、[T-07 利害關係人參與規劃](../theory/T-07-stakeholder-engagement.md)。

## 問題 3：會議當下，你該怎麼回應？

??? tip "提示"
    公開場合適合解決問題，還是適合先承認顧慮？

??? note "參考思路"
    在公開場合爭論，他只會更堅持。可以這樣說：「您提的是很關鍵的問題，產線穩定一定是最優先的。我想會後找您花半小時，專門討論產線設備要怎麼處理，可以嗎？」先承認、後私下處理。

## 問題 4：一對一會談時，你要問哪些問題？

??? tip "提示"
    目的是了解，不是說服。想想看，你需要知道哪些關於產線設備的事實與他的經驗？

??? note "參考思路"
    - 「過去有沒有類似的變更造成產線問題？當時發生了什麼？」
    - 「哪些設備最敏感？它們停機的影響是什麼？」
    - 「如果要讓您能接受，最需要先做到什麼？」

    第一個問題常常最有收穫：他的抗拒很可能來自一次痛苦的經驗，見 [P-02 變革抗拒](../psychology/P-02-resistance-to-change.md)。

## 問題 5：有哪些方案能同時滿足專案目標與他的利益？

??? tip "提示"
    試著列出三個以上的選項，不要只想「全做」或「不做」。

??? note "參考思路"
    - 產線設備先放在獨立網段，以白名單方式管理，不走新的認證流程。
    - 先挑幾台非關鍵設備試行兩週，由他的團隊評估結果。
    - 導入時程配合產線的歲修或保養期。
    - 給他的團隊在試行期內「一鍵退出」的權限。

    讓他參與選擇方案，就把他從反對者變成共同設計者。參考 [P-04 原則式談判與 BATNA](../psychology/P-04-principled-negotiation.md)。

??? abstract "總結"
    處理抗拒的利害關係人，順序是：

    1. **分辨立場與利益**，找到他真正怕的東西。
    2. **公開場合先承認顧慮**，問題留到私下處理。
    3. **一對一時以了解為目的**，特別是他過去的經驗。
    4. **一起設計方案**，讓他的顧慮變成設計輸入。
    5. **給他控制感**，例如試行、退出機制、時程選擇。
