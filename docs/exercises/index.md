# 練習總覽

**這裡有三種練習：測驗檢查你是否理解概念，引導練習帶你一步步思考一個情境，自我檢核讓你寫出完整的方案並替自己打分。**

```text
 三種練習的難度與用途

 測驗          ─►  引導練習      ─►  自我檢核
 選擇題 5 題       循序漸進 5–6 問    完整情境 + 評分表
 10 分鐘           20 分鐘            30 分鐘
 我懂了嗎？        我會想了嗎？        我做得出來嗎？
```
